# 配置与运行

## 环境和角色

| 项目 | 配置 |
| --- | --- |
| MySQL | `UPGRADE_MYSQL_DSN`，连接使用 UTC、绑定变量和单语句模式 |
| API | `serve -listen 127.0.0.1:8101`，远程访问由 HTTPS 反向代理提供 |
| 验证 | `UPGRADE_DOCKER` 绝对路径与 `UPGRADE_VALIDATION_IMAGE` 的本地镜像 ID |
| 凭据 | `UPGRADE_WORKSPACE_TOKEN` 只用于客户端。运维可按工作区和操作者撤销 |
| 可选模型 | `UPGRADE_MODEL_URL` 完整路径，`UPGRADE_MODEL_NAME`，可选 `UPGRADE_MODEL_TOKEN` |

令牌范围固定在项目和租户。维护者固定基线和发布计划、发起模型调用。开发者可以审阅补丁、选择命中和记录决定。验证员可以运行测试。管理员可以兼任这些操作。服务通过操作者 ID 记录动作，令牌原文不进数据库。

## 运行中断

每次写入使用 `Idempotency-Key`。相同键和内容返回原回执。复用同键提交新内容会返回冲突。候选和验证任务开始前先写入任务号。客户端失联时可调用 `GET /api/v1/jobs/{id}` 查询，直到任务完成或显示中断。中断保留到期记录和已保留的推理预算，由操作者决定是否发起新任务。

基线更新清除当前选集。旧补丁和测试仍可供审阅。即使仓库回到同一份文件摘要，也要在新修订重新验证。发起人领到的凭据撤销后，服务拒绝新的写入操作。

## 验证隔离

验证只运行计划中的 `composer-lock`、`php-lint`、`php-test`。PHP 测试文件必须存在于快照允许范围内。将仓库测试授权给独立验证镜像，镜像应由环境管理员构建并维护。容器用非 root UID、只读挂载、无网络、无额外权限、1 CPU、256 MiB 存储器限制与临时目录运行。输出在读取上限内计算摘要，运行日志保留耗时、退出码与观察状态。

Composer 查询还有平台、替换包、插件和外部仓库语义。内建解析器的候选只代表在给定目录中找到解。最终验证使用实际 Composer，遇到不支持的版本表达式或缺少平台信息时记录待复核。

## 模型与预算

只允许管理员配置 HTTPS 服务或字面回环地址的 HTTP 服务，模型连接不走环境代理或重定向。应用根据获批片段的字节数保守预留预算，收到服务计量后更新实际 token 数。缺失计量保留预留值，费用需要结合服务方费率。回放只用于演示，记录标为 `replay`。

## 备份与恢复

用及时备份保留工作区、快照、计划、证据、审阅和任务回执。数据库凭据与模型配置由部署环境管理。MySQL 包含二进制凭据摘要，备份要使用 `mysqldump --single-transaction --hex-blob`。恢复到独立数据库后，用原有工作区令牌检查历史批次、验证记录和导出摘要。
