# 代码库升级与迁移助手｜状态与操作契约

## 升级批次的生命周期

盘点→规划→生成候选→验证→人工采纳或退回。基线或依赖锁变化后旧测试只能作为历史证据。

## 权限与操作者

仓库维护者选择升级目标，开发者审阅补丁，测试负责人确认回归，组织管理员管理模型与费用。 在待审批与已完成状态分别检查读写范围，委托与代办保留真实操作者身份。

## 两个关键交互

1. 输入本地仓快照、目标版本、允许的目录和测试命令清单；返回升级图、阻断依赖与依据链接。
2. 审阅选择补丁与期望基线，输出可导出的 diff、验证报告、受影响文件及撤回范围。

## 业务操作与异常回执

| 操作域 | 在当前数据上的处理 | 冲突、拒绝或降级行为 |
|---|---|---|
| 仓库接入 | 获取经维护者授权的快照，白名单指定目录与可运行的测试任务，原仓库只读。 | 基线已移动时显示差异并重新确认。 |
| 依赖盘点 | 同时展示声明约束及锁定版本，串出阻断目标升级的最短依赖链。 | 没有锁文件时明确结果不可复现并要求生成基线。 |
| 影响评估 | 解析器与模型建议区分来源，引用文件行、版本指南和测试覆盖缺口。 | 仅文本同名但调用不同类型时标记待核。 |
| 迁移计划 | 计划列出前置批、预期影响文件、可用验证和预算；不可解分支转人工选择。 | 互相冲突的版本要求不得假报可解。 |
| 补丁生成 | 固定输入、模型与规则版，产物限定授权目录；维护者可对任一修改给出保留或重做理由。 | 尝试修改无关配置的补丁进入拒绝清单。 |
| 验证与证据 | 在受限环境运行已批准工具，区分环境不可用、旧版既有失败与新增回归。 | 缺依赖或测试超时不计为绿色。 |
| 审阅与采纳 | 采纳以预期基线为条件，有后继时撤回先列受影响批，导出标准补丁与冲突说明。 | 拒绝前置批后下游不能自动合并。 |
| 评测与用量 | 冻结保留集独立于提示调试，按任务统计真实通过率、费用与人改量；日志避免暴露私有源码。 | 离线录制结果不能充当真实推理质量成绩。 |

## 失联、中断及恢复

绑定仓、基线摘要、目标版本和工具链，补丁、测试、采纳决定均关联工作区快照；基线变化重新验证。 中断后先查询最后一个已持久的业务标记，再决定安全重试、补偿或人工复核。对外回执携带对象身份及业务版本。批量操作允许逐项查看成功、失败和未开始。

## 发布级业务断言

测试仅执行项目维护者批准的既有任务。网络及凭据按工作区最小授权；模型意见缺证时标记待核。 锁文件与建议可追溯到基线；未通过测试的批次不能标记可采纳。丢弃其中一批时保留原始项目及其他获准批次。
